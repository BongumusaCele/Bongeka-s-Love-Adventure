# Character atlases

Built-in imagegen edits of the supplied Bongeka, Bongumusa and Gcinile character sheets. True-alpha four-pose PNG atlases; runtime canvas splits cells and trims transparent padding, retaining the original art.

Prompt shared by each asset: create a crisp pixel-art romantic platformer atlas matching the reference small sprites, four full-body poses in an equal 2 x 2 grid: idle facing right, running left foot forward, running right foot forward, celebration holding a pink heart. Consistent scale, baseline, transparent padding, dark outlines; no labels, panels, scenery or extra characters.

Bongeka: burgundy short-sleeved top, long tiered navy denim skirt, tan sandals, dark brown skin, long black hair and black headband.
Bongumusa: black suit, white shirt, black shoes, dark brown skin, short black hair, no hat.
Gcinile: white floral crop top, denim shorts, red sneakers, warm brown skin, high bun and side-swept fringe.

Sources: character sheets supplied by the owner. Reference photographs remain local and are not published.
